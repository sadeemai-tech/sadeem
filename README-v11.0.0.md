# SADEEM v11.0.0 — "Center stage"

بناء مباشر على v10.3.0. القاعدة الحاكمة ثابتة: بلا إيموجي، بلا تدرجات، بلا
حدود جانبية زخرفية؛ جرافيت دافئ/أبيض/أسود/سكني + ليموني هادئ باعتدال.
**كل بند أدناه مُتحقَّق منه فعلياً بلقطات حقيقية من التطبيق العامل
(docs/ui-review/v11/) أو باختبارات حية موثقة.**

## الجديد (كل بند بإثبات)

1. **مسرح كامل للميزات (Stage Rails)** — كان كل شيء (الأرينا، Flows، Git،
   MCP، المكتبة…) محشوراً في عمود 320px بجانب فراغ ميت. الآن 11 لوحة
   (sessions/git/mcp/usage/dna/flows/skills/artifacts/library/wiki/arena)
   صفحات كاملة بعرض المسرح مع ترويسة مرقمة وعمود موسّط 1080px.
   لقطة المقارنة: v11/05-arena-stage.png مقابل v11-baseline/04-arena.png.
2. **الإعدادات تحت الشريط العلوي** — كانت تغطي النافذة كاملة فيختفي زر
   الإغلاق. الآن top:44px والشريط يبقى مرئياً وقابلاً للاستخدام (v11/02).
   إضافة: **قسم تحديثات جديد (21)** + Advanced أصبح 22، سكة مضغوطة بسطر
   واحد لكل قسم (22 قسماً بلا تمرير تقريباً)، المحتوى موسّط.
3. **بث التفكير/البناء بلا خطوط جانبية** — حُذف السكة الرأسية الملوّنة
   (band-rail + scan) وحُذف خط التفكير الليموني الجانبي (kb-think) وكل
   `border-inline-start` الملوّنة في التطبيق (toast/goal/blockquote/library).
   الأشرطة أصبحت بطاقات هادئة بعنوان علوي (v11 مبنية في كل لقطة محادثة).
4. **حساب محلي حقيقي** — بطاقة «إنشاء حساب / تسجيل دخول» تعمل فوق خدمة
   scrypt الموجودة (ملفات 0600، جلسات 30 يوم، throttle). تسجيل خروج وحذف
   بخطوتين. صادق: الحساب اختياري ولا يغادر الجهاز (v11/04).
5. **تحديث تلقائي صادق** — خدمة electron-updater بخلاصة generic قابلة
   للتعديل، فحص يدوي «Check now» + فحص هادئ بعد الإقلاع، لا تنزيل دون
   نقرة، تثبيت عند الإقلاع أو فوراً. ملاحظة unsigned معلنة داخل القسم.
6. **الموقع الرسمي (جديد كلياً)** — 7 صفحات (index/features/download/
   pricing/console/changelog/404) بلغة التطبيق البصرية ذاتها، بنياها 6
   وكلاء متوازون على مواصفة واحدة (website/SPEC.md)، ثنائي اللغة EN/AR
   مع 587 مفتاح ترجمة، SEO كامل (canonical/OG/Twitter/sitemap/robots/
   manifest/JSON-LD-ready)، لقطات التطبيق الحقيقية داخل الصفحات، وكونسول
   محلي صادق (تسجيل/حساب محفوظ محلياً). معاينة: `python3 -m http.server
   -d website 8046`. لقطات: docs/site-review/.
7. **وضوح الميزات** — Templates وScheduled jobs صارت بلاطتين في Quick
   actions، وقسما MCP status وScheduled ظاهران دائماً مع زر إنشاء عند
   الفراغ (يرفع الترقيم المرئي أيضاً 01→08 بلا قفزات).
8. **أرقام التحقق**: `npm test` → **159 اختبار، 158 ناجح، 0 فاشل، 1
   متخطى شرطياً**. MCP حي: Connected · 2 tools · 2ms (ui-review/51).
   أرينا حية: سبّاقان، لوحة صدارة، «merge rejected» صادقة (ui-review/50).
   بناء Windows: Setup + Portable + ZIP 11.0.0، pefile يؤكد الاسم/النسخة/
   6 أيقونات، وpy7zr يؤكد app.asar داخل المثبّت.
