# SADEEM v10.2.0 — «Works Like Codex» — الصوت، الورك تري، Plugins، Library، الـDiffs

سديم v10.2.0 — تنفيذ رسالتك الأخيرة **بندًا بندًا**: إصلاح الميكروفون من جذره،
إصلاح الورك تري وجعلها تعمل بطريقة Codex/Cursor (بعد هندسة عكسية حقيقية من
GitHub)، إضافة Plugins وLibrary، وعرض الكود قبل/بعد (diffs) داخل البث مثل
Codex وClaude Code، وإعادة تصميم الأرينا، وأقسام إعدادات جديدة — على نفس لوحة
«Monochrome + Quiet Lime» (صفر تدرجات، صفر إيموجي).

**الوكيل الذي يجب أن يُثبت أنه أنجز. / The agent that must PROVE it is done.**

---

## 1. الإدخال الصوتي — كان معطّلًا من جذرين، الآن يعمل

وجدنا **عطلين حقيقيين** (لا تخمين — من الكود):

1. **`electron/main.ts` كان يرفض إذن `media`** — معالج الأذونات كان يسمح فقط
   بـ`fullscreen` و`clipboard-sanitized-write`، فكل `getUserMedia({audio})`
   يُرفض قبل أن يبدأ التسجيل. **هذا سبب «الميكروفون لا يعمل» عندك حرفيًا.**
   الإصلاح: منح `media` + إضافة `setPermissionCheckHandler` (كروميوم يسأله
   مزامنةً عند `enumerateDevices` — بدونه يظهر «لا توجد أجهزة»).
2. **التفريغ النصي كان يفهم OpenAI فقط**: أرسل الصوت إلى
   `/audio/transcriptions` بنموذج `whisper-1` عبر المزوّد النشط — فإذا كان
   مزوّدك Z.AI/GLM أو Anthropic فالنتيجة دائمًا `NO_TRANSCRIPTION_ENDPOINT`
   أو خطأ 404. الإصلاح:
   - **خرائط مزوّدين حقيقية**: OpenAI (`whisper-1`) · Groq
     (`whisper-large-v3`) · **Z.AI (`glm-asr-2512` مع سقوط تلقائي إلى
     `glm-asr` للمفاتيح الأقدم)** · Zhipu (`open.bigmodel.cn`) · أي baseUrl
     متوافق مع OpenAI.
   - **قسم إعدادات Voice جديد** (الإعدادات ← General ← 17 Voice input):
     مزوّد التفريغ (Auto/OpenAI/Groq/Z.AI/Off) + تجاوز النموذج + ملاحظة صادقة
     بأن Anthropic/Ollama بلا مسار تفريغ (`docs/ui-review/36-settings-voice.png`).
   - **رسائل خطأ دقيقة** بدل التوست العام: `NO_API_KEY` «أضف مفتاح API…»،
     `NO_TRANSCRIPTION_ENDPOINT` «المزوّد النشط لا يدعم تحويل الصوت…»،
     «لم يُعثر على ميكروفون»، TIMEOUT… كل حالة برسالتها.

الأدلة: اختبارات أكواد الخطأ الدقيقة في `tests/v102-core.test.mjs` + اللقطة 36.

## 2. الورك تري — الآن تعمل وتُستخدم بطريقة Codex (هندسة عكسية فعلية)

استنسخنا من GitHub: **`openai/codex`** (Rust) و**`sst/opencode`** — والوثيقة
الكاملة بالأدلة في **`docs/REVERSE-ENG-CODEX-v10.2.md`**. أبرز ما وجدناه
وتبنّاه:

- **Codex يضع منتقي الورك تري تحت صندوق الكتابة في كل محادثة** → عندنا:
  شارة **`MAIN ⌄` بجوار أزرار BUILD/PLAN/DEBUG/REVIEW** تفتح قائمة «أين تعمل
  هذه الجلسة»: الشجرة الرئيسية / الورك تريات القائمة / **شجرة عمل جديدة…**
  (`docs/ui-review/31…32`).
- **الجلسة تُسلَّم (hand-off)**: الجلسة تحمل `{name, path, branch}` وكل
  تشغيل للوكيل يجري **داخل مسار الورك تري** (`workspace:` في معاملات التشغيل).
  من لوحة Workspace زر **Play «Run THIS chat in this worktree»** لكل شجرة،
  والشجرة الحالية تحمل خيطًا ليمونيًا + شارة THIS CHAT.
- **`.worktreeinclude`** (راتب Codex): ملف بجذر المستودع يسرد الملفات
  المهملة التي يحتاجها البناء (`.env`…) فتُنسخ عند إنشاء الشجرة — مُنفَّذ
  و**مُختبَر بـgit حقيقي** في `tests/v102-core.test.mjs`.
- **اكتشفنا وأصلحنا ازدواجية قاتلة**: أداة الوكيل كانت تنشئ `<name>-wt` بفرع
  `surnia/<name>` بينما خدمة الواجهة تنشئ `sadeem-<name>` بفرع `sadeem/<name>`
  — **مساران مختلفان لنفس المفهوم**. الآن مخطط واحد: `../sadeem-<name>` +
  `sadeem/<name>`، والشجرات القديمة (surnia-) ما زالت تُفهرس.
- **سياسة Codex للنموذج**: وصف `worktree_create` يحمّل النموذج قاعدتهم
  («افحص list أولاً وفضّل إعادة الاستخدام… التغييرات غير المُرحّلة لا تُنسخ»).
- الدمج بضغطة يعمل (merge + تنظيف الشجرة) — مُختبَر end-to-end بـgit فعلي.

## 3. Chat Streaming — الكود قبل/بعد داخل البث (مثل Codex وClaude Code)

- **وجدنا أن كود الـdiff في v10.1 كان ميتًا**: بطاقات الأدوات كانت تقرأ
  `parsed.oldText` — مفتاحًا لا ترسله الأدوات إطلاقًا (`edit_file` ترسل
  `old_string/new_string` و`write_file` ترسل `content`) — فشارة `+N −M`
  والمعاينة **لم يظهرا أبدًا**. أصلحنا المسار وكتبنا اختبارات تثبته.
- **`DiffView` جديد بمستوى Codex**: ترويسة ملف + `+3 −2`، تبديل
  **Unified | Split (قبل/بعد)**، هيدر هانك `@@ -1,7 +1,8 @@`، **أرقام أسطر
  مزدوجة**، إضافات بليموني وحذف بأحمر مكتوم، إبراز كلمة-كلمة داخل الأزواج
  المُستبدلة، زر «عرض كل التغييرات» للفرق الكبيرة.
- **بطاقات التعديل تُفتح تلقائيًا** — الفرق هو المحتوى، لا يحتاج نقرًا.
- المحرك: `src/lib/linediff.ts` (LCS بخلايا Uint32، تدهور آمن للملفات
  الضخمة بأرقام صادقة). الإثبات البصري: `docs/ui-review/35-diff-view.png`.

## 4. Plugins — حزم قدرات حقيقية (قراءة من نظام opencode)

- **`pluginService.ts`**: manifest JSON يُثبَّت في
  `<userData>/plugins/<id>/plugin.json` ويحقن: **خوادم MCP** (تُدمج في كل
  تشغيل وكيل تلقائيًا)، **أوامر سلاش** (تُكتب ملفات `.md` حقيقية يقرأها
  خط slashService القائم — صفر حالات خاصة)، **مهارات مضمّنة** تُعتمد في
  الجذر العالمي.
- **قسم Plugins في الإعدادات**: المثبت (تفعيل/تعطيل/حذف/كشف المجلد) + 3
  حزم بداية بضغطة (Web Pack: خادم fetch MCP + أمر `/research` · Memory Pack:
  خادم ذاكرة معرفية · Git Rituals: أوامر `/ship` و`/changelog`) + استيراد
  من **https** فقط (سقف 2MB، تحقق صارم من الـmanifest) أو ملف JSON
  (`docs/ui-review/37-settings-plugins.png`).
- مُختبَر: تثبيت → ملف الأمر يظهر → تفعيل → خوادم MCP تُحقن → حذف ينظف كل شيء.

## 5. Library — مكتبة أعمال عبر الجلسات

- **`libraryService.ts`**: فهرس `<userData>/library.json` يلتقط تلقائيًا كل
  ما ينتجه سديم: **الصور** (image_generate)، **المستندات** (make_document
  PDF/DOCX/XLSX)، **التنزيلات** (download_file)، **تصدير الجلسات**.
  إزالة تكرار بالمسار، طوابع زمنية احتكارية، وإسقاط المدخلات التي حذف ملفها.
- **واجهة Rail جديدة «10 Library»**: شبكة بطاقات ملوّنة بالنوع + فلاتر
  (ALL/IMAGE/DOCUMENT/DOWNLOAD/EXPORT/FILE) + بحث + فتح في المدير/نسيان
  (`docs/ui-review/33-library.png`).

## 6. الأرينا — من «بسيطة» إلى لوحة سباق

- بطاقات محاولات بشبكة متجاوبة: **قرص نتيجة دائري**، **أشرطة مفصّلة**
  T/M/L/D بدل أرقام جافة، **شارة diffStat** (ملفات ±أسطر — البيانات كانت
  موجودة ولم تُعرض أبدًا) + شارة تكلفة، نبض للحالة الحية.
- لوحة حية بمنصة: رتّب 1/2/3 + فروق النقاط مقابل الأول + أشرطة متحركة.
- ترويسة «Proven Arena» مع شارة LIVE نابضة أثناء السباق.

## 7. إضافات أخرى بندًا بندًا من رسالتك

- **MCP والسكيلز**: تعمل — مغطاة بحزمة الاختبارات (169 اختبارًا ناجحًا تشمل
  MCP OAuth وskillGate وMCP health)، وخوادم الـplugins تنضم لكل تشغيل.
- **قواعد الألوان ثابتة**: صفر تدرجات جديدة (وحتى النقش الشريطي الذي كتبه
  أحد المساعدين في CSS استُبدل بلون مسطّح)، صفر إيموجي، الأزرار النشطة في
  Mode/Review صارت على طريقة Codex (نص ليموني + خط سفلي بدل التعبئة
  الثقيلة)، وحركات دخول هادئة تحترم reduce-motion.
- **Worktree/Git إعدادات البحث**: مدخلات سجل الإعدادات الجديدة (voice,
  plugins, worktree) قابلة للاكتشاف من البحث الثنائي اللغة.
- **نسخة**: `APP_VERSION`/package.json = **10.2.0** (لاحظنا أن شريط العنوان
  كان يعرض قيمة قديمة — الملف `src/version.ts` هو المرجع الوحيد الآن).

1. **التفريغ الصوتي يحتاج مفتاح مزوّد يدعمه** — لا يوجد تفريغ محلي بلا

   (pefile/7zip/asar) ولم يُشغَّل على ويندوز حي هنا.

   على جهازك — نفس نموذج Claude Desktop/Codex Connectors).
