## 6. Honest caveats & known issues (non-blocking) / تحذيرات صادقة ومعروفة (لا تمنع التغليف)

These are **facts the founder must know**, not red gates:

1. **Unsigned build / إصدار غير موقّع.** No code-signing certificate was
   purchased. Windows Defender SmartScreen will show «حماية Windows لجهازك»
   on first run; the user must click *More info → Run anyway* after verifying
   the SHA-256. The download page states this explicitly. Updates are
   **manual** until a real update feed is published (the app falls back to
   `https://sadeem-website-theta.vercel.app/updates/`).
   لا توجد شهادة توقيع؛ سيظهر تحذير SmartScreen عند التشغيل الأول؛ التحديثات
   يدوية حالياً.

2. **Canonical domain not live / النطاق الرسمي غير فعّال بعد.**
   `website/lib/site.ts:8` declares `siteUrl: 'https://sadeem-ai.com'` and
   points canonical/OG/sitemap metadata there, but a live GET to
   `https://sadeem-ai.com` returned a **transport error** (does not resolve).
   The site currently serves from the Vercel preview
   `https://sadeem-website-theta.vercel.app`, which is also the hard-coded
   update feed (`:27`). DNS/canonical go-live is still pending.
   النطاق `sadeem-ai.com` لا يستجيب حالياً؛ الموقع يعمل على رابط Vercel
   التجريبي، وهو أيضاً مصدر التحديثات.

3. **Credits are BYOK / المفاتيح والرصيد.** No model credits are bundled. The
   app requires the user's own provider API key (OpenRouter/OpenAI/Anthropic/
   etc., encrypted locally) or a 7-day guest pass. «مجاني خلال الموسم العام ·
   بلا اشتراك» refers to the app itself, **not** to included model usage. The
   free plan also enforces a daily run gate (50/day).
   لا يوجد رصيد نماذج مضمّن؛ المستخدم يحضر مفتاحه الخاص أو يستخدم تصريح ضيف
   ٧ أيام، والخطة المجانية تقيد التشغيلات بـ ٥٠ يومياً.

4. **Dead CSS / تنظيف تجميلي.** `src/styles.css` still contains unused
   `.ctx-meter` rules (lines ~2368–2405, 3271, 3422, 3444); no component mounts
   them. Cosmetic cleanup candidate only.
   قواعد `.ctx-meter` ما زالت في CSS دون استخدام؛ لا تؤثر على الواجهة.

5. **Inert legacy spans in DOM / أصناف قديمة خاملة.** `PlateOrnament` still
   renders `.sc-plate-cross/.sc-plate-rule/.sc-plate-index` inside **user** rows
   (`MessageView.tsx:3597`), but `chat-art.css:33–40` forces `display:none` and
   `content:none`. They cannot paint; this is intentional compatibility, not a
   regression of the graphics wave.
   تُترك هذه الأصناف في صفوف المستخدم لأسباب توافقية لكنها مخفية بالكامل.

6. **Timing sensitivity / حساسية التوقيت.** The V1121 antifreeze/endurance
