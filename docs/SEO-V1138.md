## 1. ملخص عربي

- كل صفحة لها **عنوان ووصف فريدان**، رابط كنوني (`canonical`)، بطاقة Open Graph كاملة (النوع/العنوان/الوصف/الرابط/الصورة)، بطاقة Twitter، وتوجيه `robots` للفهرسة.
- اللغة الافتراضية `<html lang="ar" dir="rtl">`، وعند اختيار الإنجليزية يحدّث `LangProvider` اللغة والاتجاه إلى `en`/`ltr` — أي أن المحتوى الإنجليزي **إنجليزي بالكامل** ولا يبقى موسوماً كعربي.
- `hreflang ar/en/x-default` يشير إلى الرابط نفسه لأن الموقع صفحة ثنائية اللغة بعنوان واحد (لا مسارات `/ar` و `/en` منفصلة). هذا قرار صريح وليس ادعاءً بوجود نسختين منفصلتين.
- بيانات منظّمة JSON-LD: `Organization` + `SoftwareApplication` + `FAQPage`. السعر المعلن `$0` فقط خلال `FREE_SEASON`، بدون تقييمات وهمية وبدون سعر شراء مزيف.
- `sitemap.xml` يحتوي كل المسارات السبعة مع `lastmod` ثابت (`2026-11-22`)، و `robots.txt` يسمح بالزحف ويشير إلى الـ sitemap.
- صورة مشاركة اجتماعية حقيقية `1200×630 PNG` تُولَّد وقت البناء عبر `ImageResponse` (لا ملف وهمي ولا رابط خارجي).

## 2. English summary

- Every route has a **unique title/description**, canonical URL, complete Open Graph tags (`og:type/title/description/url/image`), a Twitter summary card, and explicit `index, follow` robots metadata.
- Document starts `lang="ar" dir="rtl"`; the client language toggle switches it to `en`/`ltr`, so English mode is genuinely English (not Arabic-tagged English text).
- `hreflang ar/en/x-default` self-references the same URL because this is one bilingual URL, not two separate `/ar` and `/en` routes.
- JSON-LD: `Organization` + `SoftwareApplication` + `FAQPage`. Only the honest `$0` FREE_SEASON offer is published — no aggregate rating, no fake purchasable price.
- `sitemap.xml` lists all 7 public routes with a stable `lastmod`; `robots.txt` allows all crawlers and references the sitemap.
- A real 1200×630 PNG social card is generated at build time with `ImageResponse`.
