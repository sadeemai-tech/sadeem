# SADEEM v10.3.0 — "Launch-Ready"

بناء على v10.2.0 مباشرة. القاعدة الحاكمة ثابتة: بلا إيموجي، بلا تدرجات؛ جرافيت دافئ/أبيض/أسود/سكني + ليموني هادئ باعتدال.

## الجديد (كل بند مُتحقَّق منه فعلياً)

1. **إعدادات مسطحة بنمط Codex — 20 قسماً مستقلاً** (كانت 6 مجموعات): لكل ميزة صفحتها الخاصة، بما فيها قسمَي **Git & Worktrees** و**Keyboard Shortcuts** الجديدين، وربط بحث ثنائي اللغة 1:1. (`docs/ui-review/40..43`)
2. **المعاينة الحية متعددة البيئات**: لم تعد تطلب package.json — بايثون (Django/FastAPI-uvicorn/Flask/سكربتات الدخول) + **أمر مخصص لأي بيئة** من الإعدادات ← Preview. اختبار حقيقي يشغّل خادم http.server بايثون عبر devStart ويجلب الصفحة. (`tests/v103.test.mjs`)
3. **التحكم بالجهاز — أداة `device_launch_app`** (أصبح المجموع 83 أداة): فتح تطبيقات سطح المكتب بالاسم أو المسار، عبر بوابة موافقة.
4. **الأرينا**: شريح "كيف تعمل" + مفتاح الدرجات، وإصلاحا خلل حقيقيان اكتُشفا بسباق حي: تسلسل المحاولات عند مشاركة الشجرة، واستبعاد ملفات البيئة من الفرق. سباق حي موثّق: 60 مقابل 20 ودمج مرفوض بصدق. (`docs/ui-review/45,50`)
5. **MCP حي**: خادم stdio حقيقي (`scripts/mcp-proof-server.mjs`) اتصل من التطبيق — Connected / 2 tools / طابع زمني. (`docs/ui-review/51`)
6. **قائمة السلاش الاحترافية**: 33 أمراً في 6 مجموعات مع وسائط وتنقل بلوحة المفاتيح وأوامر /settings والقفز للوحات. (`docs/ui-review/44`)
7. **الصوت**: "سجّل 3 ثوانٍ وفرّغ" داخل الإعدادات ← الصوت عبر خط الإنتاج الفعلي نفسه. (`docs/ui-review/43`)
8. **المكتبة**: دمج ويكي المستودع بتبويب داخلها (يلغي الازدواج)، وArtifacts Hub أصبح **Proof Center** باسم أوضح. (`docs/ui-review/46,47`)
9. **اقتصاد التوكنات**: بطاقة بأرقام الكاش الحقيقية ونسبة التوفير (×0.1) وحالة الضغط التلقائي. (`docs/ui-review/48`)
10. **الحركة**: lottie-web 5.13.0 + أنيميشن أحادية اللون محمّلة من الإنترنت (حالة فراغ المكتبة، تتوقف مع reduce-motion) + دخول متتالٍ للبطاقات.

## الاختبارات والبناء

- `npm test` → **159 ناجح / 0 فشل** (بينها 10 اختبارات v10.3).
- `npm run dist:win` → Setup + Portable + ZIP بأيقونة SADEEM ونسخة 10.3.0 و`Uninstall SADEEM.exe` بلا Wine (`scripts/patch-nsis.sh`).
- التحقق البنيوي: pefile (الاسم/النسخة/الأيقونات) + فتح المثبّت بـ 7z والتحقق من app.asar.
