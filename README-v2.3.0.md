## 🧠 الجديد في v2.3.0 — مستوحى حرفيًا من ملاحظاتكم

### 1. الذكاء الذي لا يرفض (أكبر إصلاح في تاريخ سورنيا)
- **عقد القدرات** في نظام التوجيه: الوكيل يعلن صراحة أنه قادر على كل شيء — قراءة أي ملف في الجهاز، البناء، الأوامر، الويب — وممنوع من قول «لا أستطيع» أو «لا أملك الأدوات».
- **التعافي التلقائي من الرفض**: إذا قال النموذج «لا أستطيع» دون تنفيذ أي أداة، يكتشفها المحرك ويحقن تصحيحًا يذكّره بقدراته الحقيقية ويعاود العمل (حتى مرتين لكل تشغيل) — بالعربية والإنجليزية.
- **بروتوكول ````surnia-tool```` النصي**: المزودون المخصصون وOpenRouter وOllama الذين تدعمهم دالة الاستدعاء الأصلية ضعيفة/مفقودة — أصبح بوسعهم استدعاء الأدوات عبر كتلة نصية يفهمها المحرك وينفذها ويحوّلها لاستدعاءات حقيقية.
- **النتيجة**: اكتب «روح ابني لي شيء» مع أي مفتاح API مخصص — سيعمل.

### 2. الجهاز كله بيتك (وصول على مستوى النظام)
- **قراءة بلا حواجز**: `read_file` / `list_dir` / `search_files` / `glob_files` تعمل في **أي مكان على القرص** — سطح المكتب، المستندات، التنزيلات، مشاريع أخرى — بلا مطالب موافقة لكل مسار (مثل Cursor وClaude Code تمامًا).
- **أداة `fs_browse`**: نظرة عامة على الأقراص ومجلدات المستخدم + استكشاف أي شجرة مجلدات مع الأحجام — اجب عن «أين ملفي؟» فورًا.
- **أداة `workspace_map`**: خريطة أي مشروع من أول استدعاء (البيانات التعريفية، السكربتات، الاعتماديات، شجرة مختصرة) — بديل عشرات الاستدعاءات.
- **حماية الأسرار بلا استثناء**: ملفات `.env` والمفاتيح الخاصة خارج مساحة العمل **تُقنّع قيمها تلقائيًا** مع الحفاظ على البنية — وإلغاء التقيين يتطلب موافقة صريحة واحدة.
- الكتابة والتنفيذ يبقيان مؤمّنين بالكامل كما كانا.

### 3. DNA الذي لا يمنع (إصلاح منطق التعلّم)
- **قاعدة استشارية صارمة**: كل سطر من DNA يُحقن الآن بعقد «إرشادات افتراضية — ليست قواعد ولا منعًا؛ طلب المستخدم الحالي يتجاوز دائمًا كل ما سبق» — انتهت حالات «لماذا لا تفعل كذا؟ / لأنك وضعت ديسلايك».
- **إصلاح التقاط الرفض**: النقر على «رفض» لموافقة أمر يسجل إشارة **ضعيفة صريحة** («رفض مرة واحدة — قد يكون مراجعة روتينية، ليست قاعدة دائمة»)، انتهاء المهلة لا يسجل أبدًا، وبحد أقصى إدخال واحد لكل تشغيل.
- **لا اختراع «ديسلايك»**: الاستخراج التلقائي ممنوع من ابتكار تفضيلات سلبية إلا بنص المستخدم الحرفي.
- **نسيان بضغطة**: زر نسيان لكل إدخال تغذية راجعة في لوحة DNA.

### 4. بث مباشر بمرتبة أدوات احترافية
- **كبسولة التشغيل الحي**: ماذا يفعل الوكيل الآن (يقرأ/يكتب/ينفذ/يفكر…)، الزمن المنقضي، عدد الأدوات، التوكنات — فوق صندوق الكتابة مباشرة.
- **بطاقات أدوات زجاجية**: أيقونة لكل نوع أداة، ملخص وسيطة ذكي، حالة حية (يدور/نجح/فشل)، مدة التنفيذ، و+N/−N لإحصاءات الفروق — مع شريط مسح متحرك أثناء التشغيل.
- **كتلة تفكير حية**: تتوسع أثناء التفكير وتنطوي تلقائيًا مع «فكّر لمدة 6 ث».
- **تثبيت تمرير ذكي**: تبقى في الأسفل أثناء البث، وتصعد بحرية مع «↓ أحدث» +N.
- إصلاح وميض أسوار الكود أثناء البث + تنفس ناعم للنص الحي.

### 5. Liquid Glass v6 — زجاج أعمق في كل مكان
- 4 مستويات زجاج (إيقاف/ناعم/متوسط/**قوي**) تُعاد معايرة الرموز فيها بالكامل.
- **توهج محيط**: شفق ضوئي بطيء خلف النافذة تلتقطه الأسطح الزجاجية كعمق.
- **صبغة تمييز**: ميرمية/تركوازية/طيني/كهرماني — 9 إعادات تنسيق حسب السمة، بلا بنفسجي.
- امتداد الزجاج للوحات والنوافذ والقوائم والبطاقات والقوائم المنسدلة والبطاقات الأدوات — والنصوص تبقى مطفية للقراءة المريحة.
- **سرعة حركة** قابلة للضبط (0.5×/1×/1.5×) واحترام كامل لتقليل الحركة والشفافية.

### 6. الإعدادات أعيد تنظيمها — «المظهر» أصبح مفصلاً
أربعة أقسام: **السمة والزجاج** (المستوى+التوهج+الصبغة) · **الخطوط** (أحجام المحرر والطرفية بمعاينة حية) · **التخطيط والكثافة** (مضغوط+عرض السجل مريح/واسع/كامل) · **الحركة** (تقليل+سرعة) — وكل شيء ببحث ثنائي اللغة.

### 7. الموسم المجاني 💚
- **سورنيا مجانية بالكامل الآن** — بوابة الدفع متوقفة: كل حدود Pro ممنوحة للجميع (أدوات الجهاز، الاستدعاءات المتوازية، كل الوكلاء الاثني عشر، MCP بلا حدود، بلا سقف يومي).
- خططا **Pro وTeam تبقيان ظاهرتين** بشارة «متوقفة» وسعر مشطوب — زر «غير مفعّلة الآن» — وتعودان لاحقًا بمقلوب مفتاح واحد (`FREE_SEASON = false`).
- تفعيل المفاتيح القديمة يستمر بالكامل.

### 8. إصلاحات طلبتوها حرفيًا
- **زر X في صفحة الاشتراك**: الطبقة لم تعد تغطي شريط العنوان — أزرار النافذة (إغلاق/تكبير/تصغير) ظاهرة ودائمة، زر إغلاق ثابت لا يختفي مع التمرير، Esc ينغلق، نقر خارج العمود يغلق.
- **تجاوز «فتحت مجلدًا وهو لا يعرف»**: الجهاز كله متاح للقراءة + fs_browse + عقد القدرات + التعافي من الرفض = يفهم ويفتح أي مجلد تفتحه له.

### 9. قدرات جديدة (طلبتم «أكثر من شيء واحد»)
- **إدخال صوتي 🎙️**: زر ميكروفون في المحرر — سجّل بالعربية أو الإنجليزية، يُنقل نصًا إلى صندوق الكتابة (عبر نقطة تحويل whisper متوافقة مع OpenAI في مزودك).
- **تصدير الجلسة HTML**: زر مشاركة — ملف HTML مستقل بأناقة التطبيق لسجل الجلسة كاملًا (RTL سليم، كود LTR).
- **«سورنيا: اشرح المحدد»**: عمل جديد في قائمة محرر الكود (Ctrl+Shift+E) — يشرح الكود المحدد **بالعربية البسيطة** مباشرة في الدردشة.
- **مساعد عام لا مبرمج فقط**: عقد القدرات يعلن صراحة مساعدية الملفات والمستندات والنظام والبحث.
