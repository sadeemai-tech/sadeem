# سديم — مشروع الدمو / SADEEM demo project

مشروع حقيقي صغير لفتحه داخل تطبيق سديم وتصويره لـ Gemini.

##how to record / طريقة التصوير
1. افتح تطبيق سديم (SADEEM) واختر **Open Workspace** → هذا المجلد `demo-project`.
2. في الشات اكتب جملة الدمو:
   > «أضف قسم "الإنجازات" بالأسفل بثلاث بطاقات بنفس التصميم، ثم شغّل المعاينة وأرني إياها.»
3. صوّر الشاشة أثناء: كتابة المهمة → استدعيات الأدوات (read_file / edit_file / preview) → المعاينة → الملخّص الأخير.
4. أعطِ الفيديو + لقطة من الشاشة لـ Gemini مع البرومبت في `docs/MARKETING-VIDEO-V1139.md`.

## لماذا هذا المشروع؟
- واجهة حقيقية بألوان الهوية (#0c1103 + #9be515) — لا واجهة مختلقة.
- ملف واحد بسيط (`index.html`) فتظهر الأدوات بوضوح في التسجيل.
- النصوص عربية صحيحة + خطوطcss — نتيجة مُرضية بصرياً بعد تعديل الوكيل.

> صادق: هذه مادة تصويرية؛ لم أنشئ حساباً ولا فيديو من هنا (صفحة /auth تقول إن الحساب يُنشأ في التطبيق أولاً، وأدواتي لا تسجّل فيديو).
