# Surnia v7.2.0 — «الوكيل الذي يرى ويتحقق»

مبنية مباشرة على أساسك v7.1.0 (المحفوظ في القرص، لم يُمس). هذه الجولة: هندسة عكسية لكودكس (OpenAI) وقدراته، إصلاح كل ما اختبرتَه بنفسك، وإكمال قوائم التصميم والقائمة القديمة.

## 1. تحكم المتصفح الحقيقي (الميزة الكبرى الجديدة)
8 أدوات CDP حقيقية عبر `webContents.debugger` — صفر اعتماديات جديدة:
`browser_navigate · browser_snapshot (عناصر مرقّمة) · browser_click · browser_type · browser_read · browser_screenshot (رؤية) · browser_eval (موافقة صريحة دائمًا) · browser_close`.
كل صفحة تُحمَّل تلوّث سجل الجلسة (taint) فتُصعّد الأوامر الخطرة بعدها — الجدار الحقيقي وليس نصيحة للنموذج. النماذج الرأسية (CLI) ترجع خطأ صادقًا لا تزييفًا.

## 2. إصلاحات الأمان — حالاتك السبع كلها مُصلحة (24/24 حالة اختبار)
| الحالة | قبل | بعد |
|---|---|---|
| `python -c "...rm -rf /..."` | warn | **danger** |
| `eval "$CMD"` | safe | **danger** |
| `$(echo rm) -rf /` | safe | **danger** |
| `x=rm; $x -rf` | safe | **warn** |
| `cat ~/.ssh/id_rsa \| curl -d @-` | safe | **danger** |
| `env \| curl` / `cat .env \| nc` | safe | **danger** |
| `fs.rmSync('/', {recursive:true})` داخل مفسّر | safe | **danger** |
- **قائمة سماح الشبكة صارت لأوامر الشل أيضًا** (كانت http_request فقط): أي curl/nc/ssh لُمضيف خارج القائمة يطلب موافقة صريحة حتى في fullAccess؛ وأمر شبكي بلا مضيف معروف = فشل مغلق.
- **renderer مصفّح**: `sandbox: true` (التعليق القديم كان كاذبًا — preload لا يستخدم Node أصلًا).
- كاشف حذر رجعي: `rm -rf "./build"` يبقى warn لا danger (لا إزعاج زائف).

## 3. إصلاح الخلل الثلاث المُثبت
1. **توجيه الأدوار حي**: spec/architect/docs→plan، explore/web-research→search، implement/refactor→edit، الضغط→context — عبر modelOverride+credsOverride مع حدث `role_route` مرئي. بدون تعريف صريح: نموذج الجلسة كالسابق (لا انحراف صامت).
2. **best_of_n أعيد بناؤه على الحلبة 2**: محاولات متوازية بنماذج مختلفة (الجلسة + عائلة مخالفة عبر pickVerifier)، الالتزام `git diff HEAD --binary + الملفات الجديدة` (لم يعد العمل الفائز يضيع)، درجة موضوعية، دمج مُتحقَّق يُرفض إن لم يتفوق.
3. **هدف الطفرة**: كانت البوابة الجديدة موصولة بملفات التشغيل ونطاقاتها — أضفنا التقارير من multi_edit/write_file أيضًا (spans كاملة).

## 4. هوامش التعديل الهش (تدقيقك)
- `write_file` فوق ملف لم يُقرأ قط = **موافقة صريحة إجبارية حتى في fullAccess** مع عرض أول 400 بايت («Overwrite UNREAD file»).
- **TS/TSX صياغة حقيقية**: esbuild خارج العملية (كما Python بالـast) — TS مكسور يُرفض قبل الحفظ لا مجرد توازن أقواس؛ وعند غياب esbuild (التطبيق المُغلّف) يهبط بتوازن أقواس بلا انهيار.

## 5. التصميم (قائمتك كاملة)
- tokens.css: سلّم خطوط 11/12/13/14/16/20/28، أقطار 4/8/14+pill، زجاج بمستويين، `.deco-brackets` للبطاقة الرئيسية فقط.
- العربية: body +1px، line-height 1.7، **منع uppercase كليًا في RTL**، `.bidi-num`/`.code-ltr` لعزل الأرقام والكود، خيار أرقام هندية/غربية.
- حلقة السياق في شريط الحالة (SVG قابل للنقر: نموذج/سياق/كلفة/كاش + ضغط الآن)، breadcrumb بعنوان النافذة، الإعدادات **صفحة كاملة بـ6 مجموعات** (16 قسمًا موزعة بلا فقدان) + مسبقات آمن/متوازن/مستقل + بطاقة الموجّه، إعداد أولي بـ3 خطوات، الترحيب بمركّب كبير وبطاقات مشاريع ومهام مشتقة (اختبارات فاشلة/TODO/تبعيات قديمة).
- Proof Ribbon (رمادي→أخضر/أحمر من أحداث حقيقية)، خريطة الثقة على الفروق + «راجع الأهم الثلاثة»، عدسة السياق، شريط زمن الجلسة مع استعادة، وضع التركيز (Esc يخرج).
- :focus-visible شامل، أهداف نقر ≥32px، حركة هادفة + reduced-motion، ثيم «تباين عالٍ» و«اتباع النظام»، تكبير 90–125% وكثافة مريح/مضغوط.
