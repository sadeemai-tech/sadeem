# SADEEM v11.5.0 — «قانون اللون والخط»

مبنية مباشرة على أساسك v11.4.1 (لم يُمَسّ المنطق الوكيل الصادق).
هذه الجولة: العلامة الرسمية الكاملة — الألوان، الخطوط، الشعار — في التطبيق والموقع معًا، وإصلاح الناف بار وإنشاء الحساب على الموقع.

## 1. قانون الألوان (في كل مكان، بلا استثناء)
- **أسود `#000` · أبيض `#FFF` · ليموني `#A3E635`** (اللون المستخرج من شعارك الرسمي) + درجات رمادية محايدة فقط.
- كل لون آخر **حُذف فعليًا لا أُعيد تسميته**: البيج (bone)، السكن (skin)، التبان (amber/teal/clay) — 311 قيمة hex و173 قيمة rgba عولجت في كل ثيمات التطبيق الست (obsidian / midnight / soft / light / high / follow) وكل ملفات CSS والمحرر (Monaco) والطرفية (xterm).
- الثيم الفاتح صار **أبيض نقي** `#FFFFFF`، والداكن أسود حقيقي `#111111`.
- الدلالات الوظيفية بقيَت بدون ألوان إضافية: ok=ليموني، warn=رمادي فاتح، bad=أبيض/أسود نقي مع الأيقونات والنصوص.

## 2. قانون الخطوط (خطّان فقط)
- **الخط الكايرو (Cairo) للعربية + Inter للإنجليزية** على كل سطح وكل صفحة.
- Instrument Serif **محذوف من الحزمة** (ملفات الخط وإشاراته جميعًا).
- IBM Plex Mono لم يعد إلا داخل الكود/الطرفية فقط (وظيفة تقنية لا اختيار تصميمي).

## 3. الشعار الرسمي
- شعارك (اللوحة الليمونية + العلامة السوداء الشعاعية) **مُحوَّل إلى SVG متجهي** من الصورة الأصلية بتتبّع دقيق (48 نقطة).
- أصبح الآن: لوگو المكوّن `Logo.tsx` في التطبيق، وشاشة الإقلاع، `build/icon.png` + `build/icon.ico` (كل المقاسات)، لوجو الموقع `favicon.svg`، وصورة OG للنشر.

## 4. الموقع v12 — الإصلاحات التي طلبتها
- **الناف بار**: قائمة همبرغر للموبايل (كان التنقل مستحيلًا عليها)، روابط **تسجيل الدخول / إنشاء حساب** في كل صفحة، تمييز الصفحة النشطة بخط ليموني، شعار حقيقي يدور عند التمرير.
- **إنشاء الحساب وتسجيل الدخول يعملان الآن فعليًا**: SHA-256 مدمج بالكامل بالجافاسكربت (لم يعد يعتمد على `crypto.subtle` الذي يغيب على `file://` — كان سبب الفشل الصامت)، والقاموس العربي مدمج داخل الصفحة (بلا fetch — يعمل offline).
- مُختبَر آليًا: إنشاء حساب → جلسة → تسجيل دخول → رفض كلمة مرور خاطئة، على `http://` و`file://` معًا.
- **صور فنية جديدة**: تماثيل كلاسيكية بمعالجة «دوتون ليموني» (أسود→ليموني→أبيض) متسقة مع الهوية، + غلاف OG جديد.
- **أيقونات احترافية SVG** لكل ميزة (درع/برق/شجرة/mcu/قفل)، **أنيميشنات متقنة**: دخول متدرّج للهيرو، شريط قدرات متحرك (marquee)، عدّادات إحصائيات، وميض مؤشر الطرفية، انتقالات ناعمة في كل الأزرار والبطاقات، وحماية كاملة لـ reduced-motion وبدون-JS.

## 5. سلاسة التطبيق
- شاشة إقلاع جديدة: أسود مسطّح + الشعار الرسمي بنبضة هادئة + شريط تقدم ليموني.
- انتقالات hover موحّدة وحلقة تركيز ليمونية في كل التطبيق، حركات محترمة لـ reduced-motion.

## 6. القياس
- **179/179 اختبارًا يمر** (بوابة تزامن الثيمات تحمي قانون الألوان من الانحراف مستقبلًا).
- typecheck نظيف، بناء كامل: `dist/` + `dist-electron/` + `dist-cli/`.
- لقطات حقيقية من التطبيق يعمل (Xvfb) في `shots-v115/`: بوابة الحساب ع/EN، مساحة العمل داكن/فاتح/عربي.

## 7. التشغيل
```bash
npm install        # يثبت كل شيء (يتطلب إنترنت أول مرة)
npm run full       # typecheck + بناء الواجهة + بناء الإلكترون + CLI
npm test           # 179 اختبارًا
npm run dist:win   # على ويندوز: NSIS + zip
node dist-cli/surnia.cjs "المهمة" --mode fullAccess
```

## 8. صادقات هذا الإصدار (ما لم يُنجز — بصراحة)
- **بناء NSIS/Windows**: يحتاج ويندوز أو wine — غير متاح في بيئة البناء هنا (السورس جاهز للبناء بـ `npm run dist:win`).
- الثيمات الست بقيت بأسمائها (نظام/فاتح/كربوني/داكن/عمق/تباين عالٍ) لكنها الآن كلها داخل قانون الألوان الواحد.
- لقطات الموقع `shot-arena/git/proof/settings.png` لا تزال من الجولة السابقة (تصوير إعدادات تشغيلي يتطلب تدخل UI يدوي) — استُبدلت لقطة الداشبورد بلقطة v11.5.0 الحقيقية.
